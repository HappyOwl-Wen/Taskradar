## What changed

- **AI Agent:** a separate, resizable chat panel supports Claude Messages, OpenAI Responses and third-party
  OpenAI-compatible APIs. Ask ordinary questions or propose changes to tasks, work blocks and ordinary Google events.
  Restricted mode previews before Apply; optional YOLO applies the current successful turn's proposals. Both modes
  retain permissions, local snapshots, Google ETags, partial-failure receipts and safe retries.
- **Chat controls:** Markdown/GFM and math, compact composer controls for models/thinking and execution mode,
  automatic model discovery, model-aware thinking levels, local chat history, automatic/manual titles, a separate
  title model and optional preset/model-generated prompt suggestions. Width is remembered and supports keyboard input.
- **Claude caching:** stable system and conversation prefixes, immutable per-turn context, bounded history and
  explicit 5-minute/default or optional 1-hour cache controls. Reported input, cache-write/read and output usage is
  separated for chat, titles and suggestions. Missing counters stay unknown. Real hit rates and charges depend on
  the provider; no production cache-warming requests are made.
- **Calendar workspace:** month/week/agenda views combine deadlines, local work blocks and selected Google calendars.
  Google reads use a local cache; ordinary event edits use staged permissions, drafts and ETags. Overlap warnings,
  next-free-slot suggestions and local preparation/commute buffers help planning, including recurring/read-only meetings.
- **Tasks:** delete into a 30-day recycle bin and restore, reschedule several tasks together, recognise more
  Chinese/German/English time expressions, save with Ctrl+Enter and expand notes when needed. Starting a focus session
  moves its task to in progress.
- **Focus and performance:** compact Pomodoro view, a completion alarm that rings until stopped, and faster task
  lists, home page and calendar with large collections. [Measured performance](https://github.com/HappyOwl-Wen/Taskradar/blob/v0.3.0/docs/PERFORMANCE.zh-CN.md).
- **Packaging and documentation:** consistent 0.3.0 versions, updated installer text, current README screenshots and
  download links, Agent usage/privacy/caching documentation, and repeatable synthetic HTTP/UI fixtures.

## Privacy and limitations

The Agent is optional and requires your own API key. Messages and relevant queried workspace data go to the configured
provider; API charges apply. Optional model titles and follow-up prompts make additional requests. Keys remain in the
system credential store; chats and proposals stay in the local database and are included in export/delete-all.
Google access remains optional and requires your own OAuth setup. See the
[Agent guide](https://github.com/HappyOwl-Wen/Taskradar/blob/v0.3.0/docs/AI_AGENT.zh-CN.md) and
[calendar guide](https://github.com/HappyOwl-Wen/Taskradar/blob/v0.3.0/docs/CALENDAR_WORKSPACE.zh-CN.md).

Text/tool responses are not streamed. No real AI or Google account was used for this release's verification, so live
authentication, gateway compatibility, planning quality and cache billing still need validation with your account.
Windows 10, other computers and accessibility tools have not been tested; the app has no automatic updater.

## 中文说明

0.3.0 相比 0.2.0，新增完整的日历工作台和 AI 聊天助手，并包含此前尚未发布的任务与番茄钟改进：

- AI 助手支持 Claude、OpenAI 和兼容 API；可普通问答，也可安排待办、工作时段与 Google 日程。
  默认受限模式先预览再应用，YOLO 模式自动应用本轮方案，已有权限和冲突检查继续生效。
- 聊天侧栏可调整宽度，支持 Markdown/公式、自动模型检测和思考等级、标题与提示词建议。
  模型和思考等级合并在输入框底部菜单，不再常驻占据上方空间。
- Claude 使用稳定提示词前缀与可选缓存 TTL，并分别展示聊天、标题、建议的服务端用量；
  未返回的统计不显示为零。截图中的缓存数字来自本地模拟服务，不代表真实命中率或费用。
- 日历支持月/周/日程列表、本地工作时段、所选 Google 日历、普通事件编辑、重叠提示和准备/通勤缓冲。
- 待办增加 30 天回收站、批量改期、更丰富的时间识别、Ctrl+Enter 保存；开始专注会将任务设为进行中。
  番茄钟增加紧凑视图和持续响铃，任务列表、首页与日历在大量任务下的性能也已优化。

推荐下载上方 **TaskRadar-Setup-0.3.0.exe**；便携版解压后运行 `TaskRadar.exe`。
更新前请退出窗口及托盘中的 TaskRadar，已有任务与设置会保留，数据库启动时自动升级。
API Key 需自行配置，消息及相关工作区数据会发送给所选服务商，API 使用费用由服务商收取。
