## What changed

- **Liquid Glass interface:** refractive surfaces, shared animated selection layers, spring transitions and anchored
  menus. Dialog reading areas retain a readable background; the collapsed sidebar stays aligned and scrollable.
  Reduced-motion and high-contrast preferences have fallbacks. Optical-map generation runs in a worker.
- **Personalized appearance:** landscape, solid color or a local PNG/JPEG/WebP background up to 8 MiB. Adjust accent
  color, transparency and blur; optionally extract the accent from your image or enable high-contrast text.
  Images stay in the browser/desktop WebView profile, with image data in IndexedDB. Appearance preferences are
  separate from database settings and are not included in the JSON database export.
- **Calendar navigation:** day view and shortcuts, clearer agenda date headings, and a visible today marker in
  light, dark and narrow layouts.
- **Draft management:** delete a pending Google operation from its list or editor with confirmation. Successful
  deletion clears the corresponding recovery input; cancellation or a failed request preserves the draft.
  Deleting a draft does not delete an existing Google event, task or work block.
- **Calendar correctness and performance:** newly created Google event IDs use the permitted base32hex alphabet;
  stable retry IDs still prevent duplicate creation. Indexed conflict lookups reduce repeated work for large
  calendars while retaining overlap warnings and free-slot suggestions.
- **Loading and animation fixes:** preserve hashed web assets needed by already-open tabs after rebuilding, recover
  failed lazy page imports, unify sidebar theme colors, and reduce main-thread work during glass transitions.

## Privacy and limitations

Google Calendar and the AI Agent remain optional. Google requires your OAuth configuration; the Agent requires your
API key and sends messages and relevant queried data to the configured provider, which may charge for usage.
API credentials remain in the operating-system credential store. No live Google or paid AI account was used for
this release verification. Other computers, Windows 10 and accessibility tools have not been verified in this run.
There is no automatic updater. Glass rendering depends on browser/GPU support; use reduced motion when preferred.

See the [calendar guide](https://github.com/HappyOwl-Wen/Taskradar/blob/v0.4.0/docs/CALENDAR_WORKSPACE.zh-CN.md),
